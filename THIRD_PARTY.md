# Third-party materials and provenance

PromptCraft AR is a fresh SPECS Base Template project created during the October 2026 build. Application scripts, deterministic example wording and MeshBuilder story symbols were authored for this project. No Quantum AR Explorer application source was incorporated. Educational concepts were mapped privately to Veristio Press's Developing AI Prompting Skills; no manuscript text or private production files are distributed.

## Snap resources

The native project uses the original Lens Studio 5.23.2 SPECS Base Template scene/render resources (including Echopark.hdr and unlit.graphShader), official Spectacles Interaction Kit 2.0.0, Spectacles UIKit 2.0.0, and LEAF 2.0.2. Runtime materials clone the project's connection material; vendor package archives are unmodified. No unused default Bitmoji package is included in the clean source payload.
